Dépôt apt d'Occitux

Les PC Occitux reçoivent les mises à jour d'ici tout seuls. Pour un PrimTux 9 :

sudo curl -fsSL https://gms64260.github.io/occitux/occitux.gpg -o /usr/share/keyrings/occitux.gpg
sudo curl -fsSL https://gms64260.github.io/occitux/occitux.sources -o /etc/apt/sources.list.d/occitux.sources
sudo apt update && sudo apt install occitux
